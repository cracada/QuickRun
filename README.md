# QuickRun快速启动器

前后用过多个快速启动器，包括但不限于AlmRun、ALTRun、RunZ、Wox、Listary、Launchy、PowerToysRun和Everything，深度使用的是AlmRun和Everything，Almrun很好用但有Bug且早已停更，Everything的定位毕竟是文件搜索，虽然习惯了也没什么，但毕竟不太顺手。不喜欢图标类的启动器所以对CLaunch和Quicker这类的无感。  

于是就有了这个私人定制版的Quickrun快速启动器。这是一款极致轻量的快速启动器，约120k的体积却集合了“自定义命令”、“Everything 搜索”和“输入回退作命令”这三个核心功能，自定义命令主要用来进行一些无文件的操作和特定指令匹配，Everything提供可执行文件的自动筛选，输入回退则可以直接将输入的字符直接当做命令执行，基本可以取代Win+R入口。
